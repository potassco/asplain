# Setting up LLM support

The current version of `asplain` uses locally served
[`ollama`](https://github.com/ollama/ollama) models to integrate LLM
functionality. To set this up please follow the list of steps below.

1. Installing `ollama`
   ([Documentation Reference](https://github.com/ollama/ollama?tab=readme-ov-file#linux))

```bash
curl -fsSL https://ollama.com/install.sh | sh
```
